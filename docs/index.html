Frequently asked

How do I add the widget?
Long-press your Home Screen and tap Edit → Add Widget, then search for Viikkonumero and pick a size. For the Lock Screen, enter edit mode on your Lock Screen and add a widget there.
Which week numbering does the app use?
ISO 8601: weeks run Monday to Sunday, and week 1 is the week containing the year's first Thursday. This is the standard used in Finland and most of Europe.
The number doesn't match another app.
That app is probably counting weeks from Sunday. Viikkonumero always uses ISO week numbers, so it will match official calendars and Finnish week numbering.
